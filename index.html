Rexload

A workout tracker for Android with a T-rex coach, built so a group of friends would actually keep training together.

Role
Solo product owner: concept, design, QA, release
Platform
Android, private distribution
Built with
AI pair programming (Claude)
Status
Live with an invite-only group

Problem

Most lifting apps are either spreadsheets with a skin or subscription funnels. I wanted one that felt fun enough to open every session, kept my data on my phone, and made training with friends feel like a shared thing rather than a feed of strangers.

Approach

I owned the product end to end. I defined a tight core loop (next workout, log sets, rest timer), gave the app a personality through a coach character, and added a friends-only feed. Then I solved distribution without an app store, including the onboarding for non-technical users.

Outcome

A shipped, self-updating app in the hands of real users. Friends install it from a private repository in about 15 minutes using a six-step illustrated guide I wrote, and every later release reaches them automatically.

A coach with a point of view

D.I.N.O. works fully offline: today's plan, post-workout reviews, flags on stalling lifts, and swaps when something hurts. An optional smart mode answers open training questions using the user's own API key.

Social, on the user's terms

The Pack is a friends-only feed with reactions and comments, joined by six-character friend codes. Only what you choose to post is shared. The full workout log never leaves the phone.

Distribution as a product problem

No store listing, so I designed the install path myself: private releases, automatic background updates that keep user data, and a troubleshooting table for every error a new user is likely to hit.

Details that earn daily use

Rest alerts that arrive on the second with the phone in a pocket, one-tap backup export, profile photos and mottos, and two complete visual themes: synthwave neon, and jungle with lava.

Private build for an invite-only group. Walkthrough available on request.

How I work

I build things I want to use, then make them good enough that other people want them too. Rexload started as my own training log and became the app my friends lift with.

I treat AI as a force multiplier, not a shortcut. I set the direction, make the product calls and test everything myself; Claude helps me get from idea to working release fast.
